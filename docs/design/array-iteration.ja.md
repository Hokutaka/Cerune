# 固定長配列の反復

[English](array-iteration.en.md)

## 構文と値の扱い

```cerune
values: [i64; 3] = [4, 7, 9];
for (value: infer in values) { print(value); }
for (index: i64, mut value: infer in values) {
    value = value + index;
    print(value);
}
print(values[1]); // 7：要素変数の変更は元の配列へ書き戻さない
```

| 項目 | 規則 |
| --- | --- |
| 対象 | 固定長配列。開始時に式全体を一度評価し、独立したコピーを保存 |
| 順番 | 添字0から長さ未満まで、昇順 |
| 要素 | 各回に値をコピー。既定は不変、`mut`ならその回のコピーを変更可能 |
| 添字 | 省略可能。書く場合は先頭の束縛、型は`i64`または`infer`。再代入不可 |
| 型指定 | 各束縛に明示型または`infer`が必要。要素型は対象から決まり、暗黙の数値変換はしない |
| スコープ | 添字・要素は本文だけで有効。同じ本文の重複宣言は診断 |
| 制御 | `continue`は次の要素へ、`break`は最内のループを終了、`return`は関数から戻る |

`in`は予約語です。`for (value: u8 in [1])`は対象が`[i64; 1]`なので型エラーです。`[1u8]`など、対象側の型を明示します。外側の変数と同名の要素変数は使えますが、定数やimport別名は隠せません。対象式は新しい束縛を導入する前のスコープで評価します。

## この規則を選ぶ理由

Ceruneの配列は値です。反復も同じ規則に合わせ、本文で元の配列を更新しても走査中のコピーは変わらないことにします。`mut`は取り出した値を変更する指定であり、元の要素への参照を得る指定ではありません。元を変更する処理には従来の添字付き`for`と配列代入を使えます。

対象の構築では、関数呼び出し・要素・既定値を既存の順序で評価し終えてから本文を開始します。最初の本文で`break`しても、この評価は省きません。対象の評価に失敗すれば本文へ入らず、本文で失敗すれば残りの要素を処理しません。既存の短絡評価も保持します。

## 共通展開と観測

フロントエンドで次へ展開し、全経路に同じ意味を渡します。

1. 対象配列を保存する不変な束縛。
2. コピーの`array_len`を保存する不変な束縛。
3. 0から始まる内部カーソルを持つ既存の`for`。本文の先頭で添字と要素を束縛し、更新部でカーソルを1増やす。

Cerune IRでは`$for_in_snapshot_*`・`$for_in_length_*`・`$for_in_cursor_*`が生成した束縛を示します。ソースからは書けない名前で、ファイルIDとヘッダー位置から決まります。型・束縛ID・条件・添字参照・更新が見えるため、別の反復ランタイムを仮定せず変換を追えます。

対象式と本文のNodeIdは展開後に割り当て、元のSpan（ファイルと位置）を保持します。生成した制御式はヘッダーへ、要素取得と束縛は対応する束縛宣言へ結び付けます。対象や本文の失敗は、その中の元の式・先行出力を記録します。内部の制御を観測できることは、ソースや外部からその値を書き換えられることを意味しません。

## 検証と範囲

[集計・検索](../../examples/array_iteration.ceru)と[各種の要素値](../../examples/array_iteration_values.ceru)を、VM・C・LLVM・QBE・WAT・Windows/Linux ASM・自前オブジェクトで既知の出力と比較します。正常例は文字列の生バイト、数値、入れ子、構造体、直和型、コピー、スコープ、ループ制御を含みます。失敗例は対象の評価と本文の停止を区別します。

[観測fixture](../../tests/fixtures/observation/array-iteration/)にはソースと各変換結果を保存しています。新しい動的確保の方式は導入せず、各経路の既存の配列コピーと格納方式を使います。コピーや検査の除去は実装上の最適化であり、評価順や値の独立性を変えてはいけません。

対象は現在の正の長さの固定長配列です。空配列・文字列反復・スライス・参照・分解パターン・iterator protocolは含みません。関数の戻り値検査も従来どおり保守的で、本文内に`return`があるだけでは関数全体の返却を保証したと判定しません。
